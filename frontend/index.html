Comparison

A flip is an observed difference between two recorded choices. No causal or fairness claim follows from it.

Framing-only pairs

Correction arm, reported separately

The correction changes decision-relevant evidence by design, so it is never folded into the framing-only comparison.

Per-arm counts

Denominators include every attempted run, failures included. Readable decisions are counted separately from correctness, which the runner does not grade yet.

Coverage — not task success

Coverage asks whether every registered attempt reached a definitive outcome. A fully recorded failure is covered; an empty run is vacuously covered. A timeout is not, because its fate is genuinely unknown.

How these numbers are counted

    Case and evidence

    Evidence relevance is declared in advance. Relying on a reliable source can be rational, so authority is preserved rather than stripped.

    Condition matrix

    Eligibility is computed, not chosen. Only baseline and framing are eligible for the framing-only comparison, and an excluded condition is always listed with its reason.

    Attempt records

    Every attempted run appears here, failures included. Select an attempt to see its raw output, parse signal, provenance, and unmeasured fields.

    Filtering changes which rows are listed here. It never changes the counts above: those are the export's own denominators over every recorded attempt.
